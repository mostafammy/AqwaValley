The Golden Rule — API Contract
Dev A defines TypeScript types for every API response on Day 1. Dev B works against these types using mock data.
When Dev A finishes the real implementation, Dev B switches with zero changes.
Example shared type (defined by Dev A, used by Dev B):
export type WellDTO = { id: string district: 'IIIIIII' | 'IIIIIII' | 'IIIIIIII' |
'IIIII' | 'III' level: number // 0-100 percent flow: number // m3/h status: 'active' | 'low' |
'critical' | 'maintenance' lat: number lng: number } export type AlertDTO = { id: string type:
'CRITICAL' | 'WARNING' | 'INFO' status: 'OPEN' | 'IN_PROGRESS' | 'RESOLVED' wellId: string
message: string createdAt: Date }
Never share code directly — share types. Dev A can rewrite the entire database schema as long as the DTO
types stay the same. Dev B can restyle every component as long as it consumes the same types. This is
what lets two people work in parallel without stepping on each other.
Risks & Mitigations
HIGH
Claude API latency (8+ seconds for irrigation
plan)
Mitigation: Streaming response + skeleton animation + cache plan
for 30 min
HIGH
Dev B blocked waiting for Auth API from Dev
A (Day 2)
Mitigation: Dev A exports TypeScript types + mock session first 2
hours. Dev B works on Design System in parallel
MEDIUM
No real IoT — how to show live alerts in
demo?
Mitigation: /api/ingest?manual=true sends reading at 1.35x baseline
→ fires critical leakage alert instantly
MEDIUM
Leaflet SSR crash in Next.js App Router
Mitigation: dynamic(() => import('./Map'), { ssr: false }) —
documented pattern, 5 minute fix
LOW
Integration Day (Day 13) reveals major bugs
Mitigation: Day 7 checkpoint + Day 14 buffer absorb surprises. Early
integration = early discovery
LOW
Arabic text layout issues in charts/tables
Mitigation: Recharts supports RTL natively. Custom SVG gauges
built by Dev B from scratch
